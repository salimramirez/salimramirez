## 👨‍💻 About me

I'm interested in designing maintainable backend systems using Domain-Driven Design, Clean Architecture, and other software design patterns. I also enjoy exploring how AI and cloud technologies can turn complex ideas into practical products.

## 🚀 Selected projects

### [uFlex](https://github.com/kiniot) — IoT telerehabilitation ecosystem

An IoT-powered telerehabilitation system connecting wearable motion sensors, edge computing, a REST API, and clinical and patient applications.

My contributions included wearable design, firmware, backend development, and the IoT–edge–application chain.

`ESP32` `Flask` `Spring Boot` `PostgreSQL` `Angular` `Kotlin` `Docker`

### [YachAI](https://github.com/teamspada/yachai) — Local AI reading tutor

An educational application that helps primary students practice reading comprehension with voice interaction and local AI, even with limited connectivity.

My contribution was the edge server running Gemma and the API connecting it with the application.

`Flutter` `Python` `FastAPI` `Ollama`

### Demy — Academy management platform

A multi-client academy management ecosystem developed through two related academic projects. [SmartEdu](https://github.com/smarteduhq) covers the web platform, while [Nistra](https://github.com/nistrahq) covers the mobile applications for administrators, teachers, and students.

I worked on much of the backend, modules across the native applications, and billing and collections modules across the web platform.

`Java` `Spring Boot` `Angular` `Kotlin` `Flutter` `Swift` `MySQL` `Docker`
